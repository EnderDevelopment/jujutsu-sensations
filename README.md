# Minecraft Bedrock Add-on: Jujutsu Sensations

Jujutsu Sensations is a Minecraft Bedrock add-on that introduces cursed energy items, technique items, combat abilities, cooldowns, recipes, sounds, particles, and a starter kit based on supernatural jujutsu combat.

## Install

1. Copy the `jujutsu_shenanigans_bp` folder into your Bedrock `development_behavior_packs` folder.
2. Copy the `jujutsu_shenanigans_rp` folder into your Bedrock `development_resource_packs` folder.
3. Create or edit a Minecraft Bedrock world.
4. Enable both the Jujutsu Shenanigans Behavior Pack and Resource Pack.
5. Enable the required Experiments or Beta APIs option if your Minecraft version requests it for Script API behavior packs.
6. Enter the world and run:

```text
/function jj:starter_kit
```

You can also package each pack folder as a separate `.mcpack` file and import the files into Minecraft.

## Use

Run `/function jj:starter_kit` to receive:

- 16 Cursed Energy items
- Divergent Fist
- Blue
- Red
- Hollow Purple
- Malevolent Shrine

Hold a technique item and use it to activate the ability. Touch devices can use the item action button, while keyboard and controller players can use the normal item-use button.

The techniques work as follows:

- Divergent Fist damages and knocks back nearby entities.
- Blue pulls nearby entities toward the player.
- Red damages and pushes nearby entities away from the player.
- Hollow Purple launches a fireball projectile in the direction the player is facing.
- Malevolent Shrine repeatedly damages and slows nearby entities for a short duration.

Each technique has its own cooldown. The current cooldown or activation message appears in the action bar.

Cursed Energy can be crafted from amethyst shards, coal, and an echo shard. The technique recipe crafts Hollow Purple from Cursed Energy, a Nether Star, and diamonds.
